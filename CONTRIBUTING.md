MIT License that covers the project (see [LICENSE](LICENSE)), unless otherwise
noted. You agree your contribution is provided “as is” without warranty.

## Development

1. Fork and clone the repository.
2. Install dependencies: `pnpm install`
3. Start dev server: `pnpm dev`
4. Run tests: `pnpm test && pnpm test:e2e`

## Pull requests

- Keep changes focused and well-tested.
- Ensure `pnpm typecheck`, `pnpm test`, and `pnpm build` pass.
- Follow existing code style.

## Reporting issues

Use GitHub Issues with a clear reproduction steps and browser version.
