# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

Please report security issues privately via GitHub Security Advisories on
[github.com/chayprabs/og-image-online](https://github.com/chayprabs/og-image-online/security/advisories/new).

Do not open public issues for undisclosed vulnerabilities.

## Scope

SocialRender processes user content locally in the browser. Server-side components are optional static hosting only.
